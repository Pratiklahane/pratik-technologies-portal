01 Open Position

Data Administrator

Help maintain reliable, secure and efficient data environments while supporting database operations and data availability.

Responsibilities

  • Monitor database performance and availability.
  • Manage database users, roles and access permissions.
  • Perform database backups and support recovery activities.
  • Identify and troubleshoot database issues.
  • Maintain data integrity, security and documentation.

Required Skills

  • Understanding of SQL and database concepts.
  • Knowledge of database administration fundamentals.
  • Basic Linux and troubleshooting skills.
  • Knowledge of backup, restore and monitoring processes.
02 Open Position

DevOps Engineer

Work on automation, continuous integration, containerization and deployment processes to improve application delivery and reliability.

Responsibilities

  • Build and maintain CI/CD pipelines using Jenkins.
  • Manage source code and branching using Git.
  • Build and manage Docker containers and images.
  • Support application deployments using Kubernetes.
  • Automate infrastructure and operational tasks.
  • Monitor applications and troubleshoot issues.

Required Skills

  • Hands-on knowledge of Linux administration.
  • Understanding of Jenkins and CI/CD concepts.
  • Knowledge of Docker and Kubernetes.
  • Basic scripting knowledge in Bash or Python.
  • Familiarity with Git and automation tools.
